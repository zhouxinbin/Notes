# 数组

类型 名称 [数量]
举例
`Int number[100]`
`Double weight[20]`

注意：数量只能是整数
C99之前元素数量必须是常量
之后版本可以拿变量

数组是一种容器
其中所有的元素具有相同的数据类型
一旦创建，不能改变大小
数组中的元素在内存中是连续依次排列的

一个数组
`Int a [10]`

a[0]-a[9]

可以出现在赋值的左边和右边
a[9]=a[1]+2;
赋值左边的叫左值

长度为0的数组
可以存在
没有用处

C99之后可以拿变量定义元素数量

```cpp
#include<stdio.h>

int main()
{
    int x,i;
    const int number=10;
    int count[number];
    for (i=0;i<number;i++)
    {
        count[i]=0;
    }
    scanf("%d",&x);
    while(x!=-1)
    {
        if (x>=0 && x<=9)
        {
            count[x]++;
        }
        scanf("%d",&x);
    }
    for(i=0; i<number;i++)
        printf("%d:%d\n",i, count[i]);
    return 0;
}
```
