# if-else 嵌套

else总是和最近的if匹配 除了大括号

```cpp
#include<stdio.h>
int main(void)
{
    int max = 0;
    int a,b,c;
    printf("请输入三个要比较大小的数 并用空格间隔开\n");
    scanf_s("%d %d %d", &a, &b, &c);

    if (a < b) {
        if (b < c) {
            max = c;
        }else {
            max = b;
        }
    }else {
        if (a < c) {
            max = c;
        }else {
            max = a;
        }
    }
    printf("%d", max);
    return 0;
}
```
