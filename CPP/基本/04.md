# 逻辑运算符

![B7FMOOC 0 ab aese aseue abue truese abee efa](../../images/Exported image 20260608165846-0.png)

与 一个为假即为假
或 一个为真即为真

数学中的区间 在C语言中用 逻辑与 表示
如 `x>4 && x<6`

判断 c 是否为大写字母
`c>='A' && c<='Z'`

`!age<20` 无论如何 逻辑运算后都等于1
`!(age<20)` 相当于 `age>=20`

![MOOC0c c GitHub 0httpswww.icourse163.orglearnZJU19...](../../images/Exported image 20260608165850-1.png)

逻辑运算 自左向右进行 如果左边能够决定结果 就不会向下进行
对于&& 左边是false 就不会进行右边
对于|| 左边是true 右边不进行
