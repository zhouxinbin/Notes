## 快速幂（Fast Exponentiation）

**定义**
快速幂用于高效计算一个数的 `n` 次幂（`a^b`），时间复杂度为 O(log₂b)。
基本思想是将指数 `b` 按二进制展开，利用幂运算的结合律，将乘法次数从 O(b) 降至 O(log b)。

**核心公式**
对于任意整数 `a` 和正整数 `b`，有：

\[
a^b = 
\begin{cases}
1, & b = 0 \\
(a^{b/2})^2, & b \text{ 为偶数} \\
a \cdot a^{b-1}, & b \text{ 为奇数}
\end{cases}
\]

实际实现中，我们采用二进制分解：

\[
b = \sum_{i=0}^{k-1} c_i \cdot 2^i, \quad c_i \in \{0,1\}
\]

则

\[
a^b = \prod_{i=0}^{k-1} a^{c_i \cdot 2^i}
\]

通过不断将 `a` 平方，同时根据当前二进制位是否为 1 决定是否累乘到结果中。

### 代码实现（模意义下）

```cpp
#include <bits/stdc++.h>
using namespace std;

// 快速幂，计算 (a^b) % p
int quick_power(int a, int b, int p) {
    int res = 1 % p;          // 处理 p=1 的特殊情况
    while (b) {
        if (b & 1) {          // 如果当前二进制位为 1
            res = (long long)res * a % p;   // 累乘
        }
        b >>= 1;              // 指数右移（相当于除以 2）
        a = (long long)a * a % p;           // 底数平方
    }
    return res;
}

int main() {
    int n;
    cin >> n;
    while (n--) {
        int a, b, p;
        cin >> a >> b >> p;
        cout << quick_power(a, b, p) << endl;
    }
    return 0;
}
```

**重要说明**
- 使用 `(long long)` 强制类型转换，防止中间乘法溢出（`a * a` 或 `res * a` 可能超过 int 范围）。
- 当 `p = 1` 时，任何数模 1 均为 0，初始化 `res = 1 % p` 直接得到正确结果。
- 该算法适用于 `a, b, p` 均在 `10^9` 数量级的情况。

## 快速幂求逆元（模意义下的除法）

**问题**
给定整数 `a` 和模数 `p`（`p` 为质数），求一个数 `x` 使得：

\[
a \cdot x \equiv 1 \pmod{p}
\]

则称 `x` 为 `a` 的乘法逆元，记作 `a^{-1}`。

**推导**
由费马小定理，当 `p` 为质数且 `a` 不是 `p` 的倍数时，有：

\[
a^{p-1} \equiv 1 \pmod{p}
\]

改写为：

\[
a \cdot a^{p-2} \equiv 1 \pmod{p}
\]

因此，`a` 的乘法逆元为 `a^{p-2} mod p`。

**使用快速幂计算逆元**
直接调用 `quick_power(a, p-2, p)` 即可。注意前提条件：`p` 是质数，且 `a % p != 0`。

### 应用示例

```cpp
// 计算 a 在模 p 下的逆元（p 为质数）
int inv = quick_power(a, p - 2, p);
```
