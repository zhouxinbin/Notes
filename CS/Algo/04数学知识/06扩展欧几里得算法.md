## 贝祖定理（裴蜀定理）

**定义**
对于任意整数 \(a, b\)，存在一对整数 \(x, y\)，使得
\[
a x + b y = \gcd(a, b).
\]

**证明**
- 若 \(b = 0\)，则 \(\gcd(a,0) = a\)，取 \(x = 1, y = 0\) 即可。
- 若 \(b > 0\)，由欧几里得算法，\(\gcd(a,b) = \gcd(b, a \bmod b)\)。
  假设存在整数 \(x', y'\) 满足
  \[
  b x' + (a \bmod b) y' = \gcd(b, a \bmod b).
  \]
  由于 \(a \bmod b = a - \lfloor a/b \rfloor \cdot b\)，代入得
  \[
  b x' + (a - \lfloor a/b \rfloor b) y' = a y' + b\big(x' - \lfloor a/b \rfloor y'\big).
  \]
  因此令 \(x = y',\; y = x' - \lfloor a/b \rfloor y'\)，即可使原式成立。

**扩展欧几里得算法（代码实现）**
通过递归翻转参数传递，减少不必要的变量交换。

```cpp
int exgcd(int a, int b, int &x, int &y) {
    if (b == 0) {
        x = 1, y = 0;
        return a;
    }
    int d = exgcd(b, a % b, y, x); // 翻转传入，x与y交换
    y -= (a / b) * x;              // 根据推导更新 y
    return d;
}
```

调用后，`x, y` 即为满足 \(a x + b y = \gcd(a,b)\) 的一组解。

## 线性同余方程

**定义**
给定整数 \(a, b, m\)，求整数 \(x\) 满足
\[
a x \equiv b \pmod{m}.
\]
当未知数指数为 1 时，称为一次同余方程（线性同余方程）。

**解的判定**
方程等价于存在整数 \(y\) 使得 \(a x - b = m y\)，即
\[
a x + m y = b. \tag{1}
\]
由贝祖定理，方程有解当且仅当 \(\gcd(a, m) \mid b\)（记 \(d = \gcd(a, m)\)）。

**求解步骤**
1. 先用扩展欧几里得算法求出一组解 \(x_0, y_0\)，满足
   \[
   a x_0 + m y_0 = d.
   \]
2. 则原方程的一个特解为
   \[
   x = x_0 \cdot \frac{b}{d}.
   \]
3. 通解为所有模 \(\dfrac{m}{d}\) 与 \(x\) 同余的整数，即
   \[
   x' \equiv x \pmod{\frac{m}{d}}.
   \]

**代码实现**
```cpp
#include <bits/stdc++.h>
using namespace std;

int exgcd(int a, int b, int &x, int &y) {
    if (b == 0) {
        x = 1, y = 0;
        return a;
    }
    int d = exgcd(b, a % b, y, x);
    y -= (a / b) * x;
    return d;
}

int main() {
    int n;
    cin >> n;
    while (n--) {
        int a, b, m, x, y;
        cin >> a >> b >> m;
        int d = exgcd(a, m, x, y);
        if (b % d) {
            cout << "impossible" << endl;
        } else {
            // 将 x 缩放为原方程的解，并确保在 0 ~ m-1 范围内
            long long res = (long long)x * (b / d) % m;
            cout << res << endl;
        }
    }
    return 0;
}
```

**注意事项**
- 输出时通常要求最小非负整数解，可对结果取模 `(m / d)` 并调整为正数。
- 如果 `b % d != 0`，则无解，输出 "impossible"。
- 在递归过程中使用 `long long` 避免乘积溢出。
