# 卡特兰数
![cate](https://cdn.jsdelivr.net/gh/zhouxinbin/Image/20260626151109870.jpeg)
## 解法
将 01 序列置于坐标系中，起点定于原点。
- 若 0 表示向右走，1 表示向上走，那么任何前缀中 **0** 的个数不少于 **1** 的个数。
- 转化为路径限制：对于路径上的任意一点，横坐标大于等于纵坐标。

题目要求的就是这样的**合法路径**数量。

由题可知，任何一条**不合法的路径**（如黑色路径），都对应一条从 `(0,0)(0,0)` 走到 `(n-1, n+1)`（或 `(n-1, n+1)`）的路径（如灰色路径）。
而任何一条 `(0,0)(0,0)` 走到 `(n-1, n+1)` 的路径，也对应一条 `(0,0)(0,0)` 走到 `(n,n)` 的不合法路径。

---

## 公式（卡特兰数）
\[
\text{res} = C_{2n}^{n} - C_{2n}^{n-1} = \frac{C_{2n}^{n}}{n+1} = \frac{(2n)!}{n! \cdot (n+1)!}
\]

---

## 代码实现

```cpp
#include <bits/stdc++.h>
using namespace std;
const int mod = 1e9 + 7;

// 快速幂（费马小定理求逆元）
int quick_power(int a, int b, int p) {
    int res = 1;
    while (b) {
        if (b & 1) res = (long long)res * a % p;
        b >>= 1;
        a = (long long)a * a % p;
    }
    return res;
}

int main() {
    int n;
    cin >> n;
    int a = 2 * n, b = n;
    long long res = 1;

    // 计算 C(2n, n)
    for (int i = a; i > a - b; i--) 
        res = res * i % mod;
    for (int i = 1; i <= b; i++) 
        res = res * quick_power(i, mod - 2, mod) % mod;  // 除以 n!

    // 除以 (n+1)
    res = res * quick_power(n + 1, mod - 2, mod) % mod;

    cout << res << endl;
    return 0;
}
```

---

## 关键点总结
- **组合数公式**：通过 \( C_{2n}^n \) 和卡特兰数公式 \(\frac{C_{2n}^{n}}{n+1}\) 直接求解。
- **快速幂**：利用费马小定理计算逆元，避免除法取模问题。
- **时间复杂度**：O(n log mod)，可在大质数取模下快速计算。
