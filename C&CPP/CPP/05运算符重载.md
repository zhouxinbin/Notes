# 重载运算符结构体排序

```cpp
struct Edge
{
    int a, b, w;
    bool operator< (const Edge &t) const
    {
        return w < t.w;
    }
} edges[M];

int main()
{
    sort(edges, edges + m);
}
```
平替：利用 sort 快排 加 cmp 函数

```cpp
struct Stu
{
    int a, b, c;
} s[1000];

bool cmp(Stu x, Stu y)
{
    return x.c < y.c;
}
// 此方法中cmp一定要放在结构体的下面 一定注意顺序！！！
```
