# string

## 字符串函数（C 风格）

`#include <cstring>`

`strcmp(s1,s2)` 字典序比较 -1、0、1
`strlen(s1)` 不包含 `'\0'`
`strcpy(s1,s2)` 把 s2 copy 给 s1

## 初始化

```cpp
string s1;                  // 空字符串
string s2 = s1;             // 拷贝
string s3 = "hiya";         // 字面量初始化
string s4(10, 'c');         // 10 个 'c'
```

**为 string 对象赋值：**

```cpp
string s1(10, 'c'), s2;   // s1 的内容是 cccccccccc; s2 是一个空字符串
s1 = s2;                  // 赋值：用 s2 的副本替换 s1 的副本
                          // 此时 s1 和 s2 都是空字符串
```

**两个 string 对象相加：**

```cpp
string s1 = "hello, ", s2 = "world\n";
string s3 = s1 + s2;      // s3 的内容是 hello, world\n
s1 += s2;                 // s1 = s1 + s2
```

## 成员方法

| 方法 | 说明 |
|------|------|
| `.empty()` | 判断是否为空，空返回 `1`，非空返回 `0` |
| `.size()` | 返回字符串长度（同 `strlen`） |
| `.back()` | 返回最后一个字符 |
| `.pop_back()` | 删除最后一个字符 |
| `.substr(i, len)` | 返回从索引 `i` 开始、长度为 `len` 的子串。省略 `len` 则到末尾 |

### 字符串拼接

`string` 与 `string` 之间、或 `string` 与字符之间可以用 `+` 拼接。注意 `+` 两侧**至少有一个**是 `string` 类型：

```cpp
string s = "Hello";
s = s + " World";   // OK
s = s + '!';        // OK
// "Hello" + "World";  // 错误：两侧都是 const char*，不能直接相加
```

### 范围 for 循环

```cpp
string s = "Hello World!";
for (char c : s)
    cout << c << endl;
```

这里的 `c` 是从 `s[i]` **复制**过来的。要修改 `s` 内部的值，改为引用：

```cpp
for (char &c : s)  // c 是 s[i] 的引用
    c = toupper(c);
```


## 代码示例

### 字符串移位

将字符串第一个字符移到最后，重复 `size` 次则恢复原样：

```cpp
for (int i = 0; i < a.size(); i++) {
    a = a.substr(1) + a[0];
}
```

### 最长连续出现的字符

找出字符串中连续出现次数最多的字符及次数：

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    while (n--) {
        char ans;
        int cnt = 0;
        string str;
        cin >> str;
        for (int i = 0; i < str.size(); i++) {
            int j = i;
            while (j < str.size() && str[j] == str[i]) j++;
            if (j - i > cnt) cnt = j - i, ans = str[i];
            i = j - 1;
        }
        cout << ans << ' ' << cnt << endl;
    }
    return 0;
}
```
