# 字符串

## 字符串本质

- **字符数组 ≠ 字符串**
  字符数组只有在末尾包含 `'\0'` 时，才能被当作字符串处理（比如用 `printf("%s")` 输出、用字符串函数操作）。
- **结束标志 `'\0'`**
  字符串以 `'\0'`（空字符，ASCII 码 0）结尾，它**标志着字符串的结束**，但**不是字符串内容的一部分**。因此字符串占用的空间 = 字符个数 + 1（`'\0'` 的位置）。
- **存储与访问**
  字符串以**字符数组**的形式存在，可以通过**数组**或**指针**来访问。
  直接遍历数组即可逐个处理字符，直到遇到 `'\0'`。
- **自动合并规则**
  两个相邻的字符串字面量（中间没有运算符或逗号隔开）会被编译器合并成一个字符串。例如：
  `"Hello " "World"` 等价于 `"Hello World"`。

## 用数组还是指针？

| 方式         | 示例                     | 适用场景                                                     |
| :----------- | :----------------------- | :----------------------------------------------------------- |
| **字符数组** | `char word[] = "Hello";` | 构造 / 存储字符串（需要可修改的内容），作为本地变量时可自动回收 |
| **字符指针** | `char *str = "Hello";`   | 处理字符串参数、指向字符串常量、动态分配内存                 |

- **数组形式**：字符串内容存放在**栈区（或静态区）**，可以安全修改（如 `word[0] = 'h';`）。
- **指针形式**：指针指向**只读的字符串字面量**（通常位于常量区），试图修改会导致未定义行为。动态分配时常用指针，如 `char *buf = (char*)malloc(100);`。

> 简单记忆：**造字符串用数组，处理字符串用指针。**

## 常用操作与注意事项

### 带长度限制的输入
```c
char x[10];
scanf("%7s", x);   // 最多读入7个字符，留一位给 '\0'
```
- `"%7s"` 告诉 `scanf` 最多取 7 个非空白字符，避免溢出。
- 读取成功会自动在末尾添加 `'\0'`。

### 空字符串
```c
char a[100] = "";   // 或 {0}
```
- 此时 `a[0] == '\0'`，是一个长度为 0 的合法字符串。
- 其余元素会被零初始化（`'\0'`）。

### 指针偏移与输出
```c
char a2[] = {'A', 'B', 'C', '\0'};
char a3[] = "ABCDEF";
cout << a2 + 1 << endl;   // 输出 "BC"
printf("%s\n", a3 + 2);   // 输出 "CDEF"
```
- `a2 + 1` 指向 `a2[1]`，`%s` 从该地址开始输出直到遇 `'\0'`。
- 注意：`a2` 必须手动添加 `'\0'` 才能安全输出。
