# 数据类型与数值

## 数据类型大小

```
sizeof(int) = 4
sizeof(short) = 2
sizeof(long) = 4
sizeof(long long) = 8
sizeof(float) = 4
sizeof(double) = 8
sizeof(char) = 1
```

## 判断两个浮点数相等

验证两个浮点数相等 等价于 两个数相减的得数是一个无穷小的值（浮点数储存形式不一定与那个数相等）

```c
float a = 9, b = 8;
int main()
{
    if (a - b < 1e-9) {
        printf("%d = %d", a, b);
    }else{
        printf("%d != %d", a, b);
    }
}
```

## 取整函数

1. 向上取整 `ceil(num)`：返回大于或等于 num 的最小整数
2. 向下取整 `floor(num)`：返回小于或等于 num 的最大整数
3. `round(num)`：对 num 进行四舍五入

## 四舍五入技巧

将一个小数加上 `0.5` 后再向下取整，可以得到其四舍五入后的整数结果。

```cpp
int m = floor(x + 0.5);
```
