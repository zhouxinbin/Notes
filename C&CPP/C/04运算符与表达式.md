# 运算符与表达式

## 算术运算符

- `i++`（后置++）：先使用 `i` 的值，再自增；表达式值为 **加前** 的值  
- `++i`（前置++）：先自增，再使用 `i` 的值；表达式值为 **加后** 的值  
- `1 % 3` 表示取余运算，结果为 `1`

## 赋值运算符

- `a += 1` 是 `a = a + 1` 的简写  
- `a = -a` 的含义：将 `a` 赋值为自身的相反数  

## 关系运算符

**运算规则**：关系成立则结果为整数 `1`，不成立结果为 `0`。

**优先级**：算术运算符  >  关系运算符  >  赋值运算符

**特别说明**：

- `==` 和 `!=` 的优先级低于其他关系运算符（`<`、`<=`、`>`、`>=`）。
- 连续的关系运算从左到右依次进行。

## 逻辑运算符

**运算结果**：只有 `0` 或 `1`  

**逻辑量**：往往是关系运算或逻辑运算的结果

| 运算符 | 描述   | 结果规则 |
| ------ | ------ | -------- |
| `!`    | 逻辑非 | 取反     |
| `&&`   | 逻辑与 | 一假即假 |
| `||`   | 逻辑或 | 一真即真 |

**常用表达**：

- 数学中的区间 `(4,6)` 用 C 语言表示为：`x > 4 && x < 6`
- 判断字符 `c` 是否为大写字母：`c >= 'A' && c <= 'Z'`

**注意**：`!age < 20` 会先做 `!age`（结果为 0 或 1），再与 20 比较，恒为真（1）。
正确的写法是 `!(age < 20)`，这等价于 `age >= 20`。

## 运算符优先级总表

| 优先级 | 运算符                            | 结合性   |
| ------ | --------------------------------- | -------- |
| 1      | `()`                              | 从左到右 |
| 2      | `!`  `+`  `-`  `++`  `--`         | 从右到左 |
| 3      | `*`  `/`  `%`                     | 从左到右 |
| 4      | `+`  `-`                          | 从左到右 |
| 5      | `<`  `<=`  `>`  `>=`              | 从左到右 |
| 6      | `==`  `!=`                        | 从左到右 |
| 7      | `&&`                              | 从左到右 |
| 8      | `||`                              | 从左到右 |
| 9      | `=`  `+=`  `-=`  `*=`  `/=`  `%=` | 从右到左 |

**短路特性**：逻辑运算从左至右进行，若左操作数已能确定最终结果，则不再计算右操作数。

- 对于 `&&`：左边为 `false` 时，右边不执行。
- 对于 `||`：左边为 `true` 时，右边不执行。

## 条件运算符（三目运算符）

**格式**：`条件 ? 表达式1 : 表达式2`

**示例**：
```c
Count = (count > 20) ? count - 10 : count + 10;
```

- 第一个操作数是条件；
- 条件为真时，取 `?` 后面的值；
- 条件为假时，取 `:` 后面的值

## 逗号运算符

**作用**：常用于 `for` 循环中，连接多个表达式。

**示例**：

```c
for (i = 10, j = 0; i >= j; i--, j++)
```
**运算规则**：从左到右依次计算，**整个逗号表达式的结果取最右边表达式的值**。

**循环中的逗号表达式示例**：

```c
#include <stdio.h>
int main()
{
    int i;
    // 逗号表达式 (0, i < 103) 只取最后一个 i < 103 作为判断条件
    for (i = 0; (0, i < 103); i++) 
        printf("!\n");
    return 0;
}
```

> 上例中，由于逗号表达式的值取决于最右边的表达式 `i < 103`，因此循环条件恒真（只要 `i < 103`），前面的 `false` 不起作用。该循环会输出 103 个 `!`。

## 表达式简化

对复杂表达式进行简化，不仅能减少计算量，还能减少甚至避免中间结果溢出。
