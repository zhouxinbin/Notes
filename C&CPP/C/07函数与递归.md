# 函数与递归

## 函数

### 基本示例

```c
#include <stdio.h>

void sum(int begin, int end)
{
    int i;
    int sum = 0;
    for (i = begin; i <= end; i++) {
        sum += i;
    }
    printf("%d\n", sum);
}

int main()
{
    sum(1, 9);
    sum(10, 19);
    sum(6, 7);
    return 0;
}
```

### 函数返回值与 void

- 如果函数有返回值，**必须使用带值的 `return`**。
- 没有返回值的函数：
  - 函数名用 **`void`**。
  - 不能使用带值的 `return`。
  - 可以没有 `return`。
  - 调用时不能将返回值赋给变量。

### 函数原型声明

- 函数头放在第一行，作为原型声明，在结尾加上分号 `;`。
- 函数主体可以放在后面。
- 目的：告诉编译器函数的名称、参数类型和返回类型。

```cpp
double max(double a, double b);

int main()
{
    int a, b, c;
    a = 5;
    b = 6;
    c = max(10, 12);
    printf("%d\n", c);
    max(12, 13);
    return 0;
}

double max(double a, double b)
{
    return a > b ? a : b;
}
```

> 编译器会自动进行类型转换，结果可能不是你所期望的。
> C 语言在调用函数时，**只能将值传递给函数**（传值调用）。

## 谓词

用于判断一个函数是否具有某一性质的函数，称为"谓词"。

## 递归

**两个条件：**

1. 调用函数本身
2. 有结束条件

**递归求阶乘：**

```c
#include <stdio.h>

// 递归函数：计算 n 的阶乘 (n!)
// 要求：n >= 0，0! = 1
unsigned long long factorial(int n) {
    // 基准条件：当 n 为 0 或 1 时，阶乘为 1
    if (n == 0 || n == 1) {
        return 1;
    }
    // 递归调用：n! = n * (n-1)!
    else {
        return n * factorial(n - 1);
    }
}
```
