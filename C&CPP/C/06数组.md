# 数组

## 一维数组

### 定义方式

```c
类型 名称[数量];
```

**示例：**

```c
int number[100];
double weight[20];
```

> 数量必须是整数
> - **C99 之前**：元素数量必须是**常量**。
> - **C99 及之后**：允许使用**变量**指定数组大小。

### 基本特性

- 数组是一种**容器**，其中所有元素具有**相同的数据类型**。
- 一旦创建，**不能改变大小**。
- 数组中的元素在内存中**连续依次排列**。

### 访问元素

```c
int a[10];
```

数组下标从 **0** 开始，有效范围：`a[0]` ~ `a[9]`。
下标可以是表达式，元素可以出现在赋值号的**左边或右边**：

```c
a[9] = a[1] + 2;
```

赋值左边的变量称为**左值**。

> ⚠️ 长度为 0 的数组可以存在（C语言允许），但通常**没有实际用处**。

## 变长数组示例（C99起）

```c
#include <stdio.h>

int main()
{
    int x, i;
    const int number = 10;      // C99后可用变量定义数组大小
    int count[number];

    // 初始化数组
    for (i = 0; i < number; i++) {
        count[i] = 0;
    }

    scanf("%d", &x);
    while (x != -1) {
        if (x >= 0 && x <= 9) {
            count[x]++;
        }
        scanf("%d", &x);
    }

    // 输出统计结果
    for (i = 0; i < number; i++)
        printf("%d:%d\n", i, count[i]);

    return 0;
}
```

## 一维数组的初始化

```c
int a[] = {5, 5, 5};
// a[0] = 5, a[1] = 5, a[2] = 5

int a[3] = {6};
// a[0] = 6, a[1] = 0, a[2] = 0

int a[6] = {[1] = 9, 9, [4] = 7};
// 下标：0  1  2  3  4  5
// 值：  0  9  9  0  7  0
```

> 💡 使用指定初始化器（designated initializers）可以灵活地对特定元素赋值。

## 二维数组

```c
int a[3][5];   // 3行5列的矩阵
```

内存中元素依然**线性排列**（按行优先存储）。
例如 `a` 的结构示意：

```
a[0][0]  a[0][1]  a[0][2]  a[0][3]  a[0][4]
a[1][0]  a[1][1]  a[1][2]  a[1][3]  a[1][4]
a[2][0]  a[2][1]  a[2][2]  a[2][3]  a[2][4]
```

---

## 二维数组的线性初始化

二维数组在内存中是按行线性存放的，因此**可以将所有数据写在一个花括号内**：

```c
int num[3][3] = {1, 2, 3, 4, 5, 6, 7, 8, 9};
```

效果等同于：

```
num[0][0]=1, num[0][1]=2, num[0][2]=3,
num[1][0]=4, num[1][1]=5, num[1][2]=6,
num[2][0]=7, num[2][1]=8, num[2][2]=9
```

## 数组大小获取

**使用 `sizeof` 运算符：**

```c
sizeof(a) / sizeof(a[0])
```

返回整个数组的元素个数。

---

## 数组的赋值

```c
int a[] = {1, 2, 3, 4, 5, 6};

// 错误：数组名不能作为左值，不能整体赋值
// int b[] = a;

// 正确：逐个元素复制
for (int i = 0; i < sizeof(a)/sizeof(a[0]); i++) {
    b[i] = a[i];
}
```

## 遍历数组的常见错误

1. 循环结束条件写为 `i <= 数组长度`（下标从0开始，最大索引是长度-1）。
2. 离开循环后继续使用循环变量 `i` 作为下标（此时可能越界）。
