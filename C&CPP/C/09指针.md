# 指针

## 指针基础概念

| 概念     | 说明                   | 示例                     |
| -------- | ---------------------- | ------------------------ |
| 数组名   | 只是一个地址，不是左值 | `a` 等价于 `&a[0]`       |
| 指针     | 是一个左值，可被赋值   | `int *p`                 |
| 指针数组 | 元素是指针的数组       | `int *p[9]`              |
| 数组指针 | 指向数组的指针         | `int (*p)[9]`            |
| 数组等价 | 数组名本质是常量指针   | `int a[] ⟺ int *const a` |

> ⚠️ **注意：** 不同类型的指针不能相互赋值。

## 指针与数组

### 数组与地址的关系

- 数组名 = 数组第一个元素的地址
- 数组变量本身表达地址，**不需要 `&`**
- 数组元素是变量，**需要 `&`**
- `[]` 和 `*` 都可以对指针或数组使用
- 数组变量是 `const` 常量指针，**不能对数组整体赋值**

```c
int a[10];
int *p = a;       // 正确：数组名本身就是地址

// 等价关系
a[0] == *a        // 第一个元素
&a[0] == a        // 第一个元素的地址
```

### 数组作为函数参数

函数**原型**中可省略参数名，以下四种写法等价：

```c
int sum(int *ar, int n);
int sum(int *,   int  );
int sum(int ar[], int n);
int sum(int [],   int  );
```

函数**定义**中不可省略参数名：

```c
int sum(int *ar,  int n) { ... }
int sum(int ar[], int n) { ... }
```

### 指针与一维数组

**`*p++` 的用法：**

- `*p++` 等价于 `*(p++)`，后置 `++` 优先级高于 `*`
- **执行顺序**：先取出 `p` 当前指向的值，再将 `p` 后移一个元素

```c
#include <stdio.h>

int main()
{
    int ac[] = {0, 1, 2, 3, 4, 5, -1};
    int *p = ac;

    // 遍历数组直到遇到 -1
    while (*p != -1)
        printf("%d ", *p++);   // 先取值，后移动指针
    printf("\n");

    // 下标方式输出所有元素
    for (int i = 0; i < sizeof(ac) / sizeof(ac[0]); i++)
        printf("%d ", ac[i]);

    return 0;
}
```

### 指针与二维数组

对于 `int array[3][5]`，`array` 代表指向第一行（含 5 个元素）的指针。

**等价关系：**

```
array[i]         ⟺  *(array + i)
array[i][j]      ⟺  *(*(array + i) + j)
array[1][0]      ⟺  **(array + 1)
array[1][3]      ⟺  *(*(array + 1) + 3)
```

**数组指针配合二维数组：**

```c
int array[2][3] = {{0,1,2},{3,4,5}};
int (*p)[3] = array;

**(p + 1)        // = array[1][0] = 3
*(*(p + 1) + 2)  // = array[1][2] = 5
```

##### 数组指针示例代码：

```c
#include <stdio.h>

int main()
{
    int array[][4] = {
        {4,  5,  6,  7},
        {8,  9, 10, 11}
    };
    int (*p)[4] = array;

    for (int i = 0; i < 2; i++)
    {
        for (int j = 0; j < 4; j++)
            printf("%2d ", *(*(p + i) + j));
        printf("\n");
    }
    return 0;
}
```

## 指针运算

### 指针相减

两个**同类型**指针相减，结果为两地址之间相差的**元素个数**：

$$\text{结果} = \frac{\text{地址差}}{\texttt{sizeof(数据类型)}}$$

### 指向指针的指针（二级指针）

```c
#include <stdio.h>

int main()
{
    int  num = 5;
    int  *p  = &num;   // 一级指针
    int **r  = &p;     // 二级指针

    printf("p   = %p\n", p);    // p 存储的地址
    printf("*p  = %d\n", *p);   // num 的值
    printf("*r  = %p\n", *r);   // 等于 p 的值
    printf("**r = %d\n", **r);  // 等于 num 的值

    return 0;
}
```

| 表达式 | 含义                        |
| ------ | --------------------------- |
| `p`    | `num` 的地址                |
| `*p`   | `num` 的值                  |
| `r`    | `p` 的地址                  |
| `*r`   | `p` 的值（即 `num` 的地址） |
| `**r`  | `num` 的值                  |

## 特殊指针类型

### `void` 指针（通用指针）

- 可以指向**任意类型**的数据
- 任意类型的指针都可赋值给 `void` 指针
- **解引用前必须强制类型转换**，因为编译器无法判断类型

```c
void *vp;
int  a  = 10;
vp = &a;                        // 合法
printf("%d", *(int *)vp);       // 解引用前须转换类型
```

### `NULL` 指针

- 当指针暂时没有明确指向时，应初始化为 `NULL`
- 有助于大型程序中的调试和错误定位

```c
int *p = NULL;
```

> ⚠️ 解引用 `NULL` 指针会导致程序崩溃，使用前须检查是否为 `NULL`。

## 引用（C++）

引用是变量的别名，与指针操作效果类似，但语法更简洁。

```cpp
#include <bits/stdc++.h>
using namespace std;

int main()
{
    int  a = 10;
    int &b = a;     // 引用：b 是 a 的别名
    int *c = &a;    // 指针：c 存储 a 的地址

    cout << "初始值：a=" << a << " b=" << b << " *c=" << *c << endl;

    b += 5;
    cout << "b+=5 后：a=" << a << " b=" << b << " *c=" << *c << endl;

    *c += 5;
    cout << "*c+=5 后：a=" << a << " b=" << b << " *c=" << *c << endl;

    return 0;
}
```

| 操作       | 引用         | 指针          |
| ---------- | ------------ | ------------- |
| 声明       | `int &b = a` | `int *c = &a` |
| 取值       | `b`          | `*c`          |
| 修改原变量 | `b += 5`     | `*c += 5`     |
| 可空       | 不可为空     | 可为 `NULL`   |
| 可重新绑定 | 不可         | 可以          |
