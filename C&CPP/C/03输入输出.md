# 输入输出

## 基本输入输出

### printf / scanf

- `scanf` 读入 `double` 类型用 `%lf`
- `printf` 输出 `double` 类型用 `%f`

`scanf` 和 `printf` 比 `cin`/`cout` 快，在面试和算法竞赛中推荐使用，防止输入输出超时。

## 字符与字符串输入输出

### 输入

- `scanf("%s", str)` — 读入字符串，遇空格/回车停止
- `fgets(str, n, stdin)` — 读入一行（**含回车符**），**不检查越界，不安全**

### 输出

- `printf("%s", str)` — 格式化输出
- `puts(str)` — 输出字符串并自动追加换行

### scanf 读入 char 的问题

`scanf` 读入 `char` 类型时，**不能**过滤掉上一个回车，会把回车当作字符读入。而 `cin` 可以自动过滤。

**解决方案：** 在 `%c` 前加 `\n` 跳过空白字符：

```c
#include <stdio.h>

int main() {
    char str[31];
    scanf("%s", str);
    char c;
    scanf("\n%c", &c);  // 跳过上次输入后的回车
    return 0;
}
```

## 输出修饰

| 格式 | 说明 | 示例 |
|------|------|------|
| `%02d` | 宽度 2 位，不足左侧补 `0` | `1` → `01` |
| `%3.1f` | 宽度 3 位，保留 1 位小数 | `1.23` → ` 1.2` |

## 读入技巧

### 防御空格与回车

当输入中可能含有多余空白字符（空格、回车）时，用读字符串代替读单个字符：

```c
char op[2];
scanf("%s", op);   // 即使输入是单个字符也能正确读入，自动过滤空白
// 使用时取 op[0]
```

### sscanf 解析已有字符串

从已有字符串中按格式提取数据：

```c
sscanf(buf, "%d%d%s%lf", &a, &b, str, &c);
```

用法与 `scanf` 一致，但数据来源是字符串 `buf` 而非标准输入。
