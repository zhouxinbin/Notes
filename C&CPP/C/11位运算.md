# 位运算

## 基本运算符

| 运算符 | 名称 | 规则               |
| :----: | :--: | ------------------ |
|  `&`   |  与  | 有一个 0 即为 0    |
|  `\|`  |  或  | 有一个 1 即为 1    |
|  `~`   |  非  | `~1=0`，`~0=1`     |
|  `^`   | 异或 | 相同为 0，不同为 1 |
|  `>>`  | 右移 | —                  |
|  `<<`  | 左移 | —                  |

## 原码、反码、补码

$$
\text{原码} = x \qquad \text{反码} = \sim x \qquad \text{补码} = \sim x + 1
$$

## 常用操作

### 求 $x$ 二进制从右数第 $k$ 位

**公式：** `x >> (k-1) & 1`

**示例：** 求十进制数 $18$ 的二进制最后一位（即第 $k=1$ 位）

```cpp
18 >> 0 & 1;
```

### lowbit($x$)

**作用：**返回 $x$ 二进制的最后一位 $1$

**公式：** `Lowbit(x) = x & (-x)`

> 其中 $-x = \sim x + 1$（即 $x$ 的补码）

**示例：**（以下均为二进制数）

```
lowbit(1010)   = 10
lowbit(101000) = 1000
```

**原理：**

$$x\& -x = x\&(\sim x+1)$$

---

$$x = \underbrace{1010\cdots }_{}1\underbrace{0\cdots0}_{n}$$

$$\sim x = \underbrace{0101\cdots}_{}0\underbrace{1\cdots1}_{n}$$

$$\sim x+1 = \underbrace{0101\cdots}_{}1\underbrace{0\cdots0}_{} \leftarrow \text{进位}$$

$$x\&(\sim x+1) = \underbrace{0\cdots0}{}1\underbrace{0\cdots0}{}$$

> **结论**：`lowbit(x) = x & (-x)`，即取出 x 二进制表示中最低位的 1。
