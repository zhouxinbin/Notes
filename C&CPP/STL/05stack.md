# stack 栈

## 定义

后进先出，竖置容器，队尾插入，队尾弹出，没有遍历

## 声明

`#include<stack>`
`stack<int> stk;`

## 函数

| 操作介绍             | 调用示例      | 时间复杂度 |
| -------------------- | ------------- | ---------- |
| 入栈（压入元素）     | `s.push(val)` | $O(1)$       |
| 出栈（弹出栈顶元素） | `s.pop()`     | $O(1)$       |
| 获取栈顶元素         | `s.top()`     | $O(1)$       |
| 判断栈是否为空       | `s.empty()`   | $O(1)$       |
| 返回栈中元素个数     | `s.size()`    | $O(1)$       |
