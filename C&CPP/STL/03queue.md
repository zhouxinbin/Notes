# queue 队列

## 定义

先进先出的数据结构

<img src="https://cdn.jsdelivr.net/gh/zhouxinbin/Image/20260704101105793.png" alt="push back P 0" style="zoom: 33%;" />

队列允许从一端新增元素，从另一端移除元素
只有队头和队尾可以被外界访问，队列没有遍历
进数据 --- 入队 push
出数据 --- 出队 pop

## 构造函数

`queue<int> que;`
`queue(const queue &que);` 构造拷贝函数

## 函数

| 操作介绍                         | 调用示例           | 时间复杂度                                                   |
| -------------------------------- | ------------------ | ------------------------------------------------------------ |
| 队尾添加元素                     | `q.push(elem)`     | $O(1)$                                                         |
| 队头移除元素                     | `q.pop()`          | $O(1)$                                                         |
| 获取队尾元素                     | `q.back()`         | $O(1)$                                                         |
| 获取队头元素                     | `q.front()`        | $O(1)$                                                         |
| 判断队列是否为空                 | `q.empty()`        | $O(1)$                                                         |
| 返回队列中元素个数               | `q.size()`         | $O(1)$                                                         |
| 清空队列（非成员函数，常用方法） | `q = queue<int>()` | $O(1)$（仅释放原内存，若元素有析构则 $O(n)$，但一般竞赛中视为 $O(1)$ 赋值） |
